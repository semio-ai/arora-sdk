# arora-index changelog

All notable changes are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/); versions follow
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-12

### Added

- Async Studio asset resolution, caller-supplied identity, and verified Storage
  and local-file fetching.
- Content-addressed public and encrypted private caching, saved pins, and
  network-only resolution fallback.
- A synchronous build helper for exact public model pins.
- Local HTTP tests and an opt-in Firebase emulator test.
